# mishrashilpa-28.github.io

Personal portfolio of Shilpa Mishra, built with Jekyll on the [al-folio](https://github.com/alshedivat/al-folio) theme
and deployed to GitHub Pages by the workflow in `.github/workflows/jekyll.yml`.

- Edit the home page: `_pages/about.md`
- Add a project: a new file in `_projects/`
- Update the resume PDF: replace `assets/pdf/Shilpa_Mishra_Resume.pdf`
- The CV page reads `assets/json/resume.json`, generated from the master CV with `scripts/make_resume_json.py` in the `_resume` folder.
