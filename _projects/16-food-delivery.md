## The problem

A clean, fast menu-and-cart experience is the core of any food delivery app.

## What it does

- **Explore menu** by category and add dishes to the cart.
- **Cart** with quantities and totals, shared across pages with React Context.
- **Login pop-up**, order page and responsive layout.

## What I learned

- Sharing state across pages with React Context instead of passing props down many levels.
- Building a responsive layout from a design, component by component.
