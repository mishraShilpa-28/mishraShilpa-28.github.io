**Code:** [GitHub](https://github.com/mishraShilpa-28/real-time-network-traffic-analyzer) · **Tech:** Python, Scapy, WebSocket, Next.js

## The problem

Seeing what is happening on a network helps diagnose problems and spot suspicious traffic.

## What it does

- **Packet capture** with Scapy, filtered by IP address.
- **Live dashboard** in Next.js fed over a WebSocket.
- **Export** captured traffic to Excel.

## What I learned

- Network protocols in practice, and streaming data from a Python backend to a web frontend.
