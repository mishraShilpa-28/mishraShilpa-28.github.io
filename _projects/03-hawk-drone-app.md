**Tech:** React Native, Expo, TypeScript, Java, Gradle, Android Studio, Firebase

## The problem

Farmers and operators needed one mobile app to request and manage drone services. As a software development intern at Hawk Aerospace I built the app's user interface.

## What it does

- **58 screens** of the Android app's user interface, built in React Native.
- **About 98 production bugs** found and fixed.
- **Documentation** of the frontend so future developers could pick up the work.

## What I learned

- Building for real users on real devices: layouts that work on small screens, and handling slow networks.
- Reading and fixing bugs in a shared production codebase instead of my own project.
- Working with a backend team: agreeing on data shapes and keeping the UI in step with the API.

*The code belongs to the company and is not public.*
